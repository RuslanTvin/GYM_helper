# GYM_helper

## About

I created this program primarily because I am interested in programming and want to practice and develop new skills. This program is used to track your progress in the gym and generally help with gym and fitness-related tasks.

I also like working out, and sometimes you want an app that can help you, but it is either not very good or you need to pay for it. So I decided to create my own.

## Features

- Pounds to kilograms conversion
- BMI calculation
- Calorie calculation
- Workout tracking
- Exercise search
- Workout statistics
- Editing and deleting workout records
- Sorting workout records

## Requirements

- Python 3.12+

## How to run

You can download or clone the repository and run the program from the console:

```bash
python3 main.py
